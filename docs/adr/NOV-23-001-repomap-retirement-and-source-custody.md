# RepoMap retirement and Source custody

Status: `Accepted`

Decided: 2026-11-23

## Decision

- Semantica와 Quanta Index는 한 번의 비호환 출하에서 RepoMap 전용 요청·빌더·응답·발행·공개 SDK/CLI·wire를 제거한다. 중간 disabled 출하와 호환 stub은 두지 않는다. 구 프레임 및 일반 publish 경로의 퇴역 ID는 효과 전에 거절한다.
- 새 제품은 Source-only를 사용한다. 일반 ItemIndex, Text/Lexical·Semantic·Symbol·Structural·History, 독립 Graph·File/Path와 ClusterCard/ModuleCard, 일반 Workset과 보조 결과는 유지한다. 공용 Graph 타입 이름이나 여러 표면이 공유하는 데이터 분류는 소유자 기준으로 판단한다.
- 이전 `Required` 계약의 signed Source·V9/ACK, payload, outbox·selector, Q projection 및 공유 Legacy 저널은 이전 승인 S/Q와 보존 root에서 읽는다. 새 후보는 검증된 이전 Source·History와 퇴역 ID 정책을 이관하고 RepoMap payload·import workspace·보호 RepoMap route를 설치하지 않는다.
- 출하 검증, 운영 선택, 저장 회수는 각각 실제 증거가 필요하다. 이전 Native 운영 선택은 D/E08의 writer 정산·Source/History 보존·선택 CAS·새 PID 조회와 첫 durable commit 전 역전환 또는 승인 동등 복구를 요구한다. 보존 종료까지 이전 실행물·root·백업·필수 read pin을 보유한다. SDK60·Large·ANN4K·제품 4K·Hybrid는 기존 원 판정과 오너를 사용한다. [현행 잔여 계획](../plans/nov-23-repomap-retirement/README.md)
