## Completion rule

이 폴더의 모든 필수 DoD를 충족하면 원래 합의한 Quanta Index 범위를 완료한 것이다. 새 에픽으로 옮겼다는 이유로 완료 조건을 줄이거나 분모를 바꾸지 않는다. 코드만 마쳤거나 외부 입력이 없어서 멈춘 상태를 전체 완료로 쓰지 않는다.
