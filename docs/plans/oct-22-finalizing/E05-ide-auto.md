# E05 — IDE·Stub·Overlay·Fast/Deep/Auto

상태는 [SSOT E05](README.md#e05). 원 요구 R25–R30, 종전 W2-15/16/17과 UX/AUTO의 기능 oracle를 소유한다. 실제 IntelliJ 비교의 최종 수용은 E08이 이 결과를 소비한다.

## Actual consumer joins

Root는 E01/E02의 실제 committed Source/owner/path를 기존 parser certificate·published Stub projection/queue에 인계하고 PUB는 SDK parent를 결합한다. existing registered Java Tree/retained group·signed SQL queue·Stub port·source-owner guarded apply·UTF8/UTF16/CRLF converter와 all-edit preflight를 재사용한다.

후속 IDE 명령은 자체 genuine Current/Original과 현재 bytes/binding을 검증한다. FULL의 deadline/권한을 재사용하지 않고 source owner guard 아래 전체 edits를 원자 적용한다. selected row 교체·late result·foreign/revision mismatch는 잘못된 위치 적용으로 성공시키지 않는다.

## Auto and replaceable logic

기존 signal→estimator/policy proposal→고정 governor→scheduler permit→dispatch/completion 재검증 경계를 유지한다. Fast/Deep/Auto 전환은 같은 intent의 absolute deadline/ledger와 immutable policy/source binding을 공유한다. missing/stale/unknown 신호를 여유 자원0비용으로 해석하지 않는다.

실험 가능한 threshold/dwell/hysteresis·gate 민감도는 정책 설정/교체 seam에서만 바꾼다. 두 유효 정책의 invariant 결과를 독립 reference ledger와 비교한다. 새 product 알고리즘/learned tuning은 측정된 결함 없이 추가하지 않는다.
