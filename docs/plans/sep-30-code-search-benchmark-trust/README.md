## Claim boundaries

- Exposed Gin 1,196 exact-name cases, identifier variants, Semble Gin 20 and ARB
  are distinct regression/case-series/workflow populations. Preserve their actual
  source view, intent, labels and request units; none is an unused holdout.
- Exact declaration/file lookup, identifier robustness, semantic/architecture
  relevance and repository workflow keep separate scoreboards. Query completion,
  output correctness and performance also remain separate.
- Report native chunks, distinct-file ranking, declaration/name spans and context
  delivery under their actual budgets. Deduplicating ten chunks cannot issue a
  ten-distinct-file request. Path-ordered prefixes are not relevance-ranked pools.
- Report every requested/eligible/attempted/completed/unsupported/incomplete/
  error/unjudged population and actual index/clock boundary. Missing cells or
  judgments cannot become empty successes or grade zero.
- `PAIR_VALID`, evidence-valid `QUALITY_DELTA` and a predeclared product-default
  decision have different authority. Use existing runners/scorers/registries;
  generated inputs, models, indexes and per-run evidence live outside the checkout.
