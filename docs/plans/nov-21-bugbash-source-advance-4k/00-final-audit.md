- **병합의 리전 수 검증 보완.** 손상 입력에서 실제 리전 ID가 0~3인데 선언 개수가 3이고 커서가 1이면, 이전 전체 스캔은 2·3·0을 읽고 ID 1을 확인하지 않았다. 전체 후보를 읽는 경우 시작부터 EOF까지 개수를 대조한다. 일부 후보만 읽는 일반 병합은 기존 커서를 사용한다. 손상 입력을 거절하고 리전 루트·개수·커서·delta가 유지되는 회귀를 추가했다. 정상 writer에서 해당 불일치가 생성된 증거는 없다. [전체 스캔](../../../crates/quanta-index-semantic/src/native/embedding/ann_directory/consolidation.rs#L524) · [잘못된 개수 회귀](../../../crates/quanta-index-semantic/src/native/embedding/tests/ann_product_tests/maintenance.rs#L5142)
- **검증 상태.** 변경한 Rust 3개 파일의 포맷과 diff 공백 검사가 통과했다. 이전 exact 메모리 회귀와 이번 리전 2건, 기존 커서 회귀를 한 Nextest 호출로 접수했다. 확인 시 실제 admission 프로세스가 공용 잠금에서 대기했으며 본문은 **NOT_RUN**이다. 기존 4K 큐도 별도 제품 입장을 기다리고 있다.

### 검색 결과 메모리와 재시작 검증

- **검색 결과 변환의 중복 예약 수정.** exact·ANN·경로 검색·lexical 교집합은 후보를 열기 전에 결과 상한을 임시 메모리로 확보한다. 상한은 요청 `top_k`와 가능한 owner 수 × 검증된 owner별 최대 벡터 수 중 작은 값이다. 파일 검색과 whole-file은 owner별 최대 1개를 사용한다. 선택 durable root가 비어 있으면 살아 있는 overlay만 센다. 전체 예약이 거절되면 결과가 생기는 만큼 늘리며, 이전 배열과 새 배열이 함께 있는 동안 두 예약을 유지한다. 선택 예약은 Lance 후보 캐시를 비우지 않는다. 반환할 때 실제 사용 슬롯만 담는 배열을 선택 예약으로 확보할 수 있으면 줄인다. 그 외에는 같은 배열의 메모리 수명을 전환하며, 전환이 거절되거나 지원되지 않으면 실제 결과 크기만 별도로 예약한다. [공유 결과 배열](../../../crates/quanta-index-semantic/src/native/embedding/ranked_hits.rs#L28) · [선택 예약 계약](../../../crates/quanta-index-core/src/index/budget.rs#L618)
- **후보 읽기에 필요한 반환 메모리 보호.** 검색 전에 전체 슬롯을 retained로 확보하면 결과가 0개여도 권한별 전역 반환 한도를 미리 잡아 필수 map page 또는 파일 경로 메모리가 거절될 수 있다. 새 런타임 경로는 live bytes를 그대로 두고, 반환 직전 단독 lease의 임시 할당을 retained로 전환한다. 부족한 반환 한도나 공유 lease는 기존 회계를 그대로 둔다. 회귀는 후보 메모리 확보, 전환 거절과 재시도, 실행 슬롯 해제, 마지막 결과 해제를 확인한다. [원자적 수명 전환](../../../crates/quanta-index-searchd-runtime/src/native_resources.rs#L1411) · [런타임 회귀](../../../crates/quanta-index-searchd-runtime/src/native_resources.rs#L2837)
- **실행별 메모리 한도.** 임시 배열은 실행별 live 한도에 포함된다. 상한 예약이 먼저 성공한 뒤 필수 작업의 추가 요구가 남은 한도를 넘는 경우는 별개다. 전역 반환 한도 수명 전환 회귀와 별도로 확인할 경계이며, 현재 제품에서 관측된 실패인지 확인되지 않았다. [실행별 live 한도](../../../crates/quanta-index-searchd-runtime/src/native_resources.rs#L1346)
- **후보 단계 메모리 반환.** ANN 라우팅 배열은 실행 중에만 사용하므로 임시 메모리로 분류한다. 마지막 리전에서 돌아오면 라우팅 배열 예약을 반환하고, 방문 owner 수와 stale 수를 계산한 뒤 owner 표와 예약도 반환한다. 작은 exact 검색은 델타 바인딩 배열을 반환한 뒤 오버레이를 처리한다. 회귀는 삭제된 owner의 불변 리전 하나를 지나 실제 오버레이 텍스트를 임베딩할 때, 랭킹 슬롯을 제외한 후보 메모리가 모두 반환됐는지 확인한다. ## 조건부 코드와 증거의 한계

- **02 파일 간 배치.** 파일당 flush의 비용이 실제 읽기 압박을 설명할 때 진행한다. 4,096→384는 이 입력의 SQL 제출 예측치다. 비용 차액·동일 root·메모리 및 실패 원자성이 채택 기준이다. [02 패킷](02-path-write-batching.md)
