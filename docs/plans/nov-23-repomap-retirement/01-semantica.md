## 공개 ranked 검색 V7

- **S `main` 구현.** 공개 daemon `query.search`는 signed Source-only V7 세대를 선택한다. Text·Regex는 Q 대표 매치를 원본 위치·snippet·highlight로 투영하며 페이지 끝에서 `result_truncated=false`를 반환한다. Symbol은 고정 Q view, References는 동일 Source의 CallGraph를 읽는다. 전용 File·Structural·RuntimeMetadata, Native Semantic·Hybrid 거절과 일반 Workset·ClusterCard는 기존 경로를 사용한다. [daemon 분기](../../../../semantica-codegraph-v2/packages/analysis/quanta-v2/crates/quanta-sdk-runtime-executor/src/client/daemon_search_execution.rs#L524) · [페이지 메타데이터](../../../../semantica-codegraph-v2/packages/analysis/quanta-v2/crates/quanta-sdk-runtime-executor/src/client/daemon_search_execution/source_only_ranked_v7.rs#L86)
- **최근 보강.** Regex는 Native 경로로 전달해 `/`가 포함된 원문 256바이트를 허용하고 257바이트를 거절한다. 빌드 메모리는 Q 엔진 상한으로 예약하고 실제 matcher에 예산 부족을 넣는 회귀가 있다. Text·Regex는 Open 전에 64KiB Release 메모리를 확보하고, ACK된 동일 Q peer·세션·view의 해제를 최대 1초 동안 재시도한다. Open ACK를 받지 못한 세션은 Q 만료 정리가 회수한다. [Regex 경계 회귀](../../../../semantica-codegraph-v2/packages/analysis/quanta-v2/crates/quanta-sdk-runtime-executor/src/client/query_handlers/search_handler/native_ranked_search_v7_tests.rs#L235) · [컴파일 예산 회귀](../../../../semantica-codegraph-v2/packages/analysis/quanta-v2/crates/quanta-runtime/src/sdk/search_builder/index_owner_env_authority/source_only_ranked_regex_v7.rs#L127) · [세션 정리](../../../../semantica-codegraph-v2/packages/analysis/quanta-v2/crates/quanta-runtime/src/sdk/search_builder/index_owner_env_authority/source_only_ranked_text_session_v7.rs#L181)
- **기존 IFX150 정리 회귀.** 실제 Q Open ACK 직후 취소를 주입한다. 공개 SDK의 typed `Cancelled`와 같은 Q 세션의 `Released` 상태, Release ACK 기반 settlement 및 남은 target pin 0을 단언한다. Text와 Regex는 같은 세션 정리 경로를 쓴다. [정리 회귀와 실행 상태](04-integration-acceptance.md#ranked-search-v7-acceptance)
- **기존 S 소켓 회귀.** 설치 승인에 결속된 단일 저장소에서 Q의 FULL→DELTA 게시 계보를 대조한다. 시작 전 읽은 durable Source snapshot과 공개 Attach 및 각 성공 `query.search` 응답을 비교한다. Detach 뒤 같은 Source pointer와 Q view가 유지돼야 한다. FULL·DELTA 각각의 ranked 검색은 IFX150 SDK exact에 연결돼 있다. S `d191b93fc089` 재검토에서 ranked search 담당의 추가 코드 작업은 확인되지 않았다. Q Regex API 합류와 두 exact의 signed Linux 본문 실행이 남았다.
