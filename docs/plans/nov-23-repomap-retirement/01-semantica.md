# 01 · Semantica 호출자·발행·복구

Semantica의 공개 호출과 새 세대 발행·복구 작업이다. 후보 구현은 진행 중이며 컴파일과 실제 제품 검증은 **NOT_RUN**이다. 아래 현재 코드 설명은 제거 전 기준이다. 관련 티켓은 [Quanta Index](02-quanta-index.md), [회수](03-storage-retirement.md), [통합 검증](04-integration-acceptance.md)이다.
