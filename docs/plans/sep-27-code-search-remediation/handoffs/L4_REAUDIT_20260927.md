## Findings and fixes

1. **P2 — preview regex memory admission undercount, observed.** A valid
   `needle\w{120}` pattern has a mandatory literal and compiles through the
   existing dialect/estimator. A standalone pinned-engine `System` allocator
   probe measured 20,035,301 peak requested bytes during compilation, above
   the previous 16,777,216-byte preview charge. The
   [probe source and raw result](l4-proof/regex-memory-probe-20260927/provenance.json)
   are diagnostic evidence, not process RSS.
2. `RegexExecutor` now exposes a validated compilation plan. The preview
   reserves its 16 MiB base before AST/HIR work, then 256 logical bytes per
   estimated NFA state before the engine builds automata. A repeated leaf
   reuses one executor; two distinct high-cost leaves exceeding the request's
   64 MiB preview ledger explicitly refuse only the preview. Selected IDs,
   scores and order remain mandatory search results. The old `compile` entry
   point uses the same plan and compiled matcher; truth/range behavior remains
   on one engine.
3. The SDK regression now uses a caller-owned state root, releases the harness
   runtime lease, starts the actual `quanta-index-searchd` binary, verifies
   decomposed-NFC original/normalized spans and all three highlights, stops
   it, and repeats after process restart. Initial diagnostics failed with
   `STATE_ROOT_IN_USE` while the harness still held the root; the final test
   releases that owner before spawning the binary.

The new state-proportional charge is a policy mitigation, **not** an
allocator-enforced total heap ceiling. Capture-heavy probes through the new
planning API reached 15,089,900 peak requested bytes for a 65,534-byte valid
pattern before engine compilation and 22,659,940 bytes over plan plus compile.
Eight further Unicode-fold, class-repetition and alternation patterns also
measured below the new logical charge. These samples do not establish a
worst-case upper bound. See
[L4_REGEX_BUDGET_RESIDUAL.md](L4_REGEX_BUDGET_RESIDUAL.md) for the remaining
architectural requirement.
